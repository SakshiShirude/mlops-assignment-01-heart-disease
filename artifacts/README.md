Run `python -m src.eda` and `python -m src.train` to generate the EDA plots, serialized model, model metadata, evaluation summary, classification reports, confusion matrices, and ROC curves in this directory. The EDA and training outputs in this workspace were generated from UCI dataset ID 45. Generated PNG, JSON, and joblib files are ignored by Git; the report embeds the overview figure and records the measured metrics, while CI uploads the generated files as a workflow artifact.
